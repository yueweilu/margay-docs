# Skills

Skills are pre-built tools that extend Margay's capabilities.

## Browsing skills

1. Click the settings gear and select **Skills**
2. Browse the available skills catalog

![Skills catalog](/screenshots/en/skills-panel.png)

## Adding a new skill

Click the **+** or **Add Skill** button to add a new skill from the catalog or import one.

![Add Skill](/screenshots/en/skills-add.png)
